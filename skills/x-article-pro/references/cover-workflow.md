# 唯一封面入口：cover-editorial-collage

本流程的文章封面只能使用 `cover-editorial-collage`。这包括新做、重做、改字和调整构图；不并用或切换其他封面 Skill，不回到旧版自由拼图或原图直出。用户明确不要封面时可以省略封面，不能用省略标记掩盖另一种封面流程。

## 真实接入

1. 执行 `scripts/resolve_dependencies.py --stage cover --json`，读取返回的 `entry_path` 对应的完整 SKILL.md。依赖不存在或哈希不一致时保留实际错误，不绕过或自行补写同名 Skill。
2. 给它本篇已定正文、标题、新闻主体、关键限定、已打开的真实素材及其用途。固定用途为 X Article cover、画幅 5:2，默认工作尺寸 2560×1024；在首行和画幅约束中一致指定。2500×1000 也满足 5:2，最终记录实际像素，不将请求尺寸当成结果。
3. 内部使用 `--out-type prompt`，按它的主题分析、构图选择、标题层级、色彩及材质要求得到实际生成提示词。默认 template 只是一份调用格式，不算成图。不存在 `--out-type image` 参数。
4. 将这份提示词和实际参考图交给当前可用图像生成/编辑工具。底层工具是该 Skill 的渲染后端，遵循工具自身的参考图、输出和编辑要求；不另外调用通用封面 Skill，也不绕过本 Skill 重新写一套无关提示词。只有明确要求成稿或封面时才执行本步，Skill 维护期间不生图。
5. 保存实际成图，再检查真实像素比例、标题中文字、主体辨识、图像保真、拼贴层次与缩略图焦点。不合格时仍经同一个 Skill 修正，不能切到另一种封面方案。生成失败或缺少实际成图时，该条封面保持未完成。

## 新闻适配

- 保留其撕纸、杂志拼贴、摄影剪贴、印刷颗粒、字图交错与明确视觉层级；构图由当前新闻决定，不把所有新闻做成同一张图换标题。
- 真实人物、产品形态、UI 含义、图表数值和关键限定不得因风格化而变成虚构事实。复杂完整图表与截图保留在正文，封面选择有辨识度的主体和局部。
- 用已核验的短标题和必要副标题；不编刊号、日期、引文、评价或品牌拼写来填微文案。拼贴装饰可以抽象，不能伪装新闻现场或证据。
- 正文至少一张真实来源图继续独立保留。编辑拼贴封面不取代它，也不冒充官方原图。

## 记录与交付

`cover.json` 必须包含：

- `generator_skill: "cover-editorial-collage"`。
- `prompt`：实际交给渲染工具的完整提示词，不是调用模板。
- `kind: "editorial_composite"`，以及实际像素、素材清单、事件联系与构图记录。
- `ai_assisted`：按实际工具使用填写；使用生成式图像工具时为 `true`，在元数据、evidence 和可见图注标明「编辑合成，含 AI 辅助示意」。

结构校验会拒绝其他生成入口、缺少入口记录、缺少实际 prompt 和原图代替拼贴封面的记录；它不靠一个字符串证明实际读过 Skill 或生成过图片。验收还要核对本次执行、实际参考输入与成图。

对用户交付实际封面，不把内部提示词与核验记录塞入公开稿；只有用户另要提示词才单独提供。

## 内部调用示例

```text
使用 $cover-editorial-collage --out-type prompt
主题词：<本篇真实新闻对象与短标题>
副标题：<正文支持的必要限定，可留空>
画幅比例：5:2，工作画布 2560×1024
语言：中文，保留产品正式名称
用途：X Article cover，extra-wide horizontal banner
情绪倾向：<根据这条新闻选择>
真实素材：<已打开的参考图绝对路径、对应内容与用途>
保真约束：<人物、界面、数据、产品形态必须保留的部分>
禁用元素：伪造新闻场景、假刊号、无关小字、并排截图卡片、霓虹机器人
```

这段是传入该 Skill 的任务参数；其输出还要实际用于生图，不能直接当作封面交付。
