# X文章-pro

**唯一默认模式：AIHOT 主要事实 + 独立表述的新闻简报 + 单列的相关新闻与最新进展。** 保留事实，不保留原文句法；不是全文复制器，也不走长篇分析、个人观点或“信息增量文章”路线。本规则替代旧版“标题正文一字不改”。

## 必须执行的文字约束

1. **主要事实不丢不变。** 先整理指定 AIHOT 条目的事件、主体、时间、版本、关键变化、数字与单位、适用范围和重要限定，再独立组织语言。保留“官方称／测试显示／计划／预览／截至某日”等证据强度，不把发布方声明改写成公认结论。
2. **独立表述，不照抄。** 标题、正文和非空 caption 均重新表述。按事实重组句子，不逐句替换同义词，不沿用特色比喻、观点句和收尾；产品名、基准名、必要术语与数字可以准确保留。不得为了降低相似度修改事实。
3. **写新闻，不扩成评论。** 直接交代发生了什么、具体变化与适用条件。默认不写个人观点、宏大意义、行业趋势推演、竞争格局、读者建议或抒情结尾。必要术语／测试口径说明只能是有来源的简短背景，量化边界见 [简报契约](references/news-brief-contract.md)；没有字数下限，不为凑长度扩写。
4. **补充单列。** 主新闻之后才放「相关新闻与最新进展｜截至 YYYY-MM-DD」，只收入同事件、已核实且标明实际日期的补充。不得把补查新事实混进主新闻，或假称 AIHOT 已写到。没有可靠新进展时省略该节并在内部记录查证结果；不造更新、不拿无关热点填充。
5. **未通过就修正，不绕验收。** 逐项检查事实保留、独立表述、无大段分析、补充隔离、标题及 caption 兑现，再绑定最终文字哈希。运行当前 v4 校验；失败即修稿或保留 incomplete，不能改回 v3 复制模式、删审校记录或降低版本取得 PASS。机器检查不等于“零抄袭”认证，语义和事实仍需逐项对照。

## 先判断交付对象

- 只更新、安装或检查 Skill：只维护技能和离线测试，不抓当天新闻，不生成文章、封面或试稿，不改现有批次。
- 指定一篇、链接或续接批次：保留指定条目、栏目和顺序，不重新挑题。
- 批量任务：一条 AIHOT 新闻一个独立目录；数量按用户要求，未指定沿用精选前十条，不拿全站流冒充精选。
- 只改图：只改所指图片／排版，文字不动。只改文字且要求图不变时保留图片字节、图注和封面记录。
- 只取得摘要或节选：如实记录内容范围；已知事实足够时写相应长度的简报，缺关键事实时保留缺口，不冒充取得全文，不扩写成未取得的“原文”。

## 流程和依赖

先运行 `scripts/resolve_dependencies.py --json`，读取返回的绝对入口，按 [依赖路由](references/dependency-routing.md) 执行。

1. **取指定 AIHOT 材料。** 使用 `aihot` 的当前说明获取真实条目，留存实际源文本、原始响应、URL、日期、采集时间与内容范围。
2. **提取事实后独立写简报。** 完整读取 [简报契约](references/news-brief-contract.md)，先做主要事实清单，再重新表述；复核关键数字、限定与发布状态。
3. **同事件补查与真实插图。** 按 [取材与配图](references/reporting.md) 核对必要事实、相关新闻及最新进展；新增信息只进独立补充节。图片的获取、打开检查、图注和证据流程不变。
4. **封面保持原流程。** 唯一入口仍为 `cover-editorial-collage`，完整遵守 [封面接入](references/cover-workflow.md)：实际 5:2 编辑拼贴成图、真实素材、实际 prompt、生成标签及看图验收；封面不代替正文真实图。
5. **记录、包装、校验。** 按 [交付格式](references/delivery-format.md) 使用 `delivery_version: 4`、`text_mode: aihot-news-brief`。运行 `validate_brief.py` 和 `validate_delivery.py --current`，再实际测试文字／图片复制。仅交实际完成项。

`dbs-content`、`human-writing`、`dbs-content-value`、`humanizer-zh` 和旧 `ai-news-to-x` 不参与当前文字流程；不借润色、去 AI 味或“增强深度”引入大段分析。历史 v2/v3 文件与校验器只维护旧包，不决定新稿规则，也不自动迁移旧稿。依赖安装与封面 Skill 本体不变。

## 交付边界

- 标题、正文、caption 和图文预览继续独立。caption 可空；需要时写一条简短、独立、事实可兑现的摘要，不摘抄原文，不做悬念钩子，不把完整 caption 放回正文。
- 图片／图注独立排版，不进入 `body.txt` 或正文文字复制。公开稿默认不附研究链接和核验附录，必要来源归属、署名及素材要求照留；完整证据在内部文件中保存。
- 不自动发布到 X，不建立定时任务，不修改其他 Skill。脚本 PASS 不代替看图、复制实测或真实来源核查。
